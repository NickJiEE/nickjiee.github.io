Modular Power Hub

An intelligent dual-I/O power management system with automatic source switching.

The Modular Power Hub is a professional-grade power management solution designed for modern electronics projects. This intelligent system provides seamless automatic switching between USB-A and USB-C inputs while delivering clean, regulated power through multiple output rails. Built with comprehensive protection circuits, it eliminates power source uncertainty and protects valuable components from electrical faults.

For more details, check out the GitHub repository!
