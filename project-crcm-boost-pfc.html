CrCM Boost PFC

A 100 W universal-input CrCM boost PFC converter designed and verified in Simulink/Simscape, with generated C and STM32G4 target support.

This project implements a 100 W critical-conduction-mode boost PFC converter for 90–264 VAC, 50/60 Hz input and a regulated 400 VDC output bus. The controller shapes the input current by restarting each switching cycle after the inductor current returns to zero.

Control and Verification

The discrete controller includes zero-current detection, variable-frequency switching, input-voltage feedforward, output-voltage regulation, startup sequencing, and overcurrent/overvoltage protection. The converter was verified under startup, steady-state, no-load, reduced-load, and load-step conditions.

  • Input: 90–264 VAC, 50/60 Hz
  • Output: 400 VDC, 100 W
  • Rated-load PF: 0.991–0.999
  • Maximum modeled efficiency: 98.2%
  • Maximum switching frequency: approximately 476 kHz

Embedded Implementation

The controller was separated into a code-generation-compatible model, converted to C using Embedded Coder, and verified through software-in-the-loop testing. It was also successfully cross-compiled for an STM32G4 / NUCLEO-G474RE target using STM32CubeMX and the GNU Arm toolchain.

For complete design details and simulation results, check out the GitHub repository !
