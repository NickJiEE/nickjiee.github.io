Dual-Core ML Accelerator

A dual-core hardware accelerator for the attention mechanism in transformer models, synthesized and place-and-routed in TSMC 65nm targeting 1 GHz.

This project implements a dual-core hardware accelerator for scaled dot-product attention (Q×K) used in transformer-based ML models. Each core features an 8×8 2D systolic array of MAC units operating on 8-bit integer vectors, synthesized in TSMC 65nm and fully place-and-routed targeting 1 GHz using Synopsys Design Compiler and Cadence Innovus.

Beginning from a single-core RTL design, the work progressively builds toward dual-core parallelism across independent clock domains, fixed-point output normalization, hierarchical synthesis with SRAM hard blocks, and sparsity-aware optimizations — all validated through gate-level simulation with SDF back-annotation. A 4-phase req/ack asynchronous CDC bridge handles partial sum exchange between the two clock domains without synchronizing the full data bus.

Key optimizations — including pipelining the normalization critical path and hardening the async handshake — improved WNS by over 6 ns while cutting total power by ~50% and area by ~67% versus the unoptimized baseline. Row-level sparsity was also implemented, skipping normalization for low-energy rows and reducing single-core power from 83.2 mW to 64.9 mW.
